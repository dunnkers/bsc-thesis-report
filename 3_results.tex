\section{Results}\label{sec:results}
The data-set was tested under several configuration conditions. Different- pixels size configurations and classifiers were used, all using a $10$-fold cross validation setup. The study focused on two main classifiers: a \textit{Support Vector Machine} using LibSVM \citep{chang2011libsvm} and \textit{Gradient Boosting} using XGBoost \citep{chen2016xgboost}. A per-cache accuracy box-plot is to be seen in Figure~\ref{fig:boxplot-svm}

Shown in the figure is that mean accuracy does not fall below xx\% for any fold, and does not exceed xx\% for any fold.
